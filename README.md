# Fantasy Premier League Model

## Overview

This project is my attempt to build an FPL prediction and optimisation model from scratch.

The goal is to understand the mechanics behind the Excel/Python models used by experienced FPL managers, while developing practical skills in Python, data analysis and optimisation.

## Current Progress

Currently:
- Pulling live player data from the FPL API
- Cleaning and organising player information
- Creating player metrics such as expected goal involvement per 90
- Exploring how underlying statistics can be converted into expected FPL points

## Planned Features

Future goals:
- Expected points model
- Fixture difficulty adjustments
- Player projections
- Squad optimisation using mathematical programming
- Transfer recommendations
- Interactive dashboard
